# Финальный проект: SQL, JDBC, Hibernate + Redis

## Суть проекта

Есть реляционная БД MySQL (схема `world`: таблицы `city`, `country`, `country_language`).
Есть частый запрос, который тормозит: «дай город + его страну + языки страны».

**Идея:** вынести все нужные данные из MySQL в Redis (key-value хранилище в памяти)
один раз при старте, а потом на точечных запросах читать из Redis.

**Результат:** Redis отвечает на точечные запросы заметно быстрее MySQL.

Зачем нужен DTO (CityCountry) — простыми словами

Entity — это «строка архива». Объект City привязан к сессии Hibernate: часть его данных ленивая (страна подтянется отдельным SQL, языки — ещё одним). Пока сессия открыта — всё живо; сессия закрылась — ленивые поля недоступны (LazyInitializationException). Такой объект «приклеен» к базе, в кэш его не положишь.

DTO — это «справка из архива». CityCountry — самодостаточная карточка: один раз скопировали в неё всё нужное (город + его страна + языки) — и карточка живёт своей жизнью. Ей не нужны ни сессия, ни БД.
